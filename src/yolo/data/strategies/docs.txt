names:     default dictionary exported from cvat.

palette:   list of [r,g,b] colors, must have as many elements as names; r,g,b expected as integers.

labels:    what label folder to use from yolo/data/labels.

split_ratio?: override default train/val split ratio (note: this is also overridden by instants.split_ratio and instants.index_selection[].split_ratio)

instants?: property that defines what indices to use during training, per instant
  from?: dataset           value can be either 'dataset' or 'detailed_dataset'
  split_ratio?: override default train/val split ratio (note: this is also overridden by instants.index_selection[].split_ratio)

  index_selection:         list of specifications, accessed by the current training instant to determine which image indices are to be used during train/val split

exact same usage as per DatasetManifest.query, at least either gt or lt must be defined, note that in this case 'instants.from' MUST be defined
both gt and lt are lists of [K,V] pairs, where K is a src/dataset constant that begins with `D_` if from=dataset, or `DD_` if from=detailed_dataset
  - {
      gt?:[[D_SPOON,1],],  the indices will have >= counts of the specified items
      lt?:[[D_FORK,0],],   the indices will have <= counts of the specified items
                           if both gt and lt are present, the indices will be the intersection of gt and lt
      split_ratio?:        value between 0 and 1, specifies how much of the indices will be split into train/val
    }

note that if all the index_selection items are of this type, then from can be safely omitted
  - {
      indices:[],          directly define the indices of the images to consider
      split_ratio?:        same as before
    }

  - {
      train:[1,]           the indices of the images that will be used for training
      val:[5,]             the indices of the images that will be used for validation
    }
